PinSight Demo Page

用于演示区域截图、标注、贴图与长截图的示例页面 —— 内容够长，方便演示滚动拼接。

1. 区域截图

按 Ctrl+Shift+A 唤出冻结层，拖出选区即可开始标注。选区四角与边线均有手柄，可精确调整。

Ctrl+Shift+A区域截图冻结层

2. 标注工具

矩形 R / 椭圆 E / 箭头 A / 直线 L / 画笔 D / 高亮 H / 马赛克 M / 序号 N / 文字 T / 测量 G / 自由套索 F。

所有标注支持 Ctrl+Z / Ctrl+Y 撤销重做，颜色与线宽跟随工具栏。

3. 贴图

按 P 把选区钉在屏幕上：置顶、可缩放、可点击穿透、支持分组热键与屏幕边缘吸附，重启后自动恢复。

4. 长截图

Ctrl+Shift+L 进入长截图模式，选区后自动滚动并逐帧拼接。固定表头剔除、静止帧判定、反向滚动识别，纵向横向都支持。

能力说明
纵向拼接重叠区搜索 + 平均绝对差
横向拼接转置法复用同一拼接引擎
上限20000px / 400 帧
手动模式自己滚动，程序只负责拼

5. 离线 OCR

Windows.Media.Ocr / Apple Vision / Tesseract，三平台完全离线。工具栏一键识别，CLI `pinsight shot --ocr` 整屏识别。

6. 录屏

选区 / 全屏 / 前台窗口三种模式，4–60fps，分辨率预设，摄像头画中画，系统声音与麦克风混音。MP4 需要 ffmpeg，否则回退 GIF。

7. 取色器

Ctrl+Shift+K 全局吸管，HEX / RGB / HSL 三种格式，一键复制。

8. GIF 编辑

trim / crop / 加文字 / 转 MP4，命令行一条搞定：pinsight gif trim clip.gif --start 2 --end 20

9. 图床上传

编辑器一键上传，链接直达剪贴板；本地后端默认落盘，也可切换 HTTP / 预置服务商。

10. MCP 服务

pinsight.exe --mcp 启动 stdio 服务，10 个工具：capture_screenshot、capture_region、pin_image、list_pins、close_pin、start_recording、stop_recording、long_screenshot、ocr_image、get_status。Claude Desktop / Cursor 直接调用。

11. CLI 无头模式

不开窗口、不建 GL 上下文，适合脚本与远程会话：pinsight shot --region 100,100,640,480 --out s.png
